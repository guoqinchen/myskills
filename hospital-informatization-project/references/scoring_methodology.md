# 综合评分法标准指南

## 一、评分方法概述

### 1.1 评分方法选择

医院信息化建设项目招标采购采用**综合评分法**，即最大限度地满足招标文件实质性要求，按照招标文件中规定的各项因素进行综合评审后，以评标总得分最高的投标人作为中标候选供应商。

### 1.2 法律依据

- 《中华人民共和国政府采购法》第二十二条
- 《政府采购货物和服务招标投标管理办法》（财政部令第87号）第五十五条
- 综合评分法中的价格分统一采用低价优先法计算

### 1.3 评分权重分配原则

| 评分类别 | 建议权重范围 | 说明 |
|----------|-------------|------|
| 价格评分 | 10%-30% | 不得低于10%，一般项目建议20%-30% |
| 功能/技术评分 | 40%-60% | 核心评分项，建议50% |
| 商务评分 | 10%-30% | 资质、业绩、服务，建议20% |
| 合计 | 100% | |

权重分配说明：
- 技术复杂、定制化程度高的项目，功能评分权重可提高至60%
- 标准化产品采购项目，价格评分权重可提高至30%
- 价格分权重不得低于10%

## 二、价格评分标准

### 2.1 计算公式

采用**低价优先法**：

```
价格得分 = (基准价 / 投标报价) × 价格分满分
```

- 基准价 = 满足招标文件全部实质性要求的最低有效投标报价
- 计算结果四舍五入保留两位小数
- 投标报价超过预算限价的为无效投标

### 2.2 示例计算

假设：
- 预算限价：100万元
- 价格分满分：30分
- 投标人A报价：80万元
- 投标人B报价：85万元
- 投标人C报价：90万元

计算：
- 基准价 = 80万元（最低有效报价）
- 投标人A价格分 = (80/80) × 30 = 30.00分
- 投标人B价格分 = (80/85) × 30 = 28.24分
- 投标人C价格分 = (80/90) × 30 = 26.67分

### 2.3 价格分异常处理

- 投标报价低于其他有效投标报价算术平均值30%以上的，评标委员会应当要求投标人做出书面说明并提供相关证明材料
- 投标人不能合理说明或不能提供证明材料的，视为低于成本投标，其投标应作无效投标处理

## 三、功能评分标准

### 3.1 评分项设计原则

1. **可量化**：每个评分项必须有明确的评分标准和分值区间
2. **可验证**：评分依据可通过演示、测试、文档审查等方式验证
3. **无歧义**：评分标准表述清晰，避免主观判断空间过大
4. **公平性**：不得指向特定品牌或供应商

### 3.2 标准评分项与分值分配

| 序号 | 评分项 | 建议分值 | 评分方式 |
|------|--------|----------|----------|
| 1 | 总体技术方案 | 8-10 | 主观评分（优/良/中/差） |
| 2 | 系统架构设计 | 5-8 | 主观评分 |
| 3 | 功能响应度 | 10-15 | 客观评分（逐项对比） |
| 4 | 系统演示/原型 | 5-10 | 客观评分（有/无/部分） |
| 5 | 数据安全方案 | 3-5 | 主观评分 |
| 6 | 实施方案 | 3-5 | 主观评分 |
| 7 | 培训方案 | 2-4 | 主观评分 |
| 8 | 售后服务方案 | 2-4 | 主观评分 |
| 合计 | | 40-60 | |

### 3.3 主观评分标准模板

每个主观评分项采用区间评分：

```
评分项：总体技术方案（满分8分）
- 优（8-7分）：方案完整详实，技术先进，架构合理，充分理解项目需求，
  实施路径清晰，风险控制措施完善
- 良（6-5分）：方案基本完整，技术可行，架构基本合理，能理解项目需求，
  实施路径可行，有基本风险控制措施
- 中（4-3分）：方案有缺失，技术方案一般，架构简单，对需求理解有限，
  实施路径不够清晰
- 差（2-0分）：方案不完整，技术方案有明显缺陷，或未提供方案
```

### 3.4 功能响应度评分方法

1. 将招标文件技术需求逐项列出（每项编号）
2. 投标人逐项响应（完全响应/部分响应/不响应）
3. 完全响应得满分，每项不响应扣减约定分值
4. 带有★号的关键需求不响应视为无效投标

```
功能响应度评分（满分15分）：
- 完全响应全部需求得15分
- 每有一项非关键需求不响应扣1分
- 带有★号的需求为关键需求，任何一项不响应视为无效投标
- 每有一项非关键需求部分响应扣0.5分
```

## 四、商务评分标准

### 4.1 标准评分项与分值分配

| 序号 | 评分项 | 建议分值 | 评分方式 |
|------|--------|----------|----------|
| 1 | 企业资质 | 3-5 | 客观评分（有/无） |
| 2 | 类似业绩 | 4-8 | 客观评分（数量） |
| 3 | 售后服务 | 3-5 | 客观+主观 |
| 4 | 团队配置 | 2-4 | 客观评分（认证） |
| 5 | 本地化服务 | 1-3 | 客观评分（有/无） |
| 合计 | | 15-25 | |

### 4.2 企业资质评分细则

| 资质项 | 分值 | 说明 |
|--------|------|------|
| ISO 9001质量管理体系认证 | 1分 | 有效期内 |
| ISO 27001信息安全管理体系认证 | 1分 | 有效期内 |
| CMMI 3级认证 | 2分 | 有效期内 |
| CMMI 5级认证 | 2分 | 替代CMMI 3级，不重复计分 |
| ITSS信息技术服务标准认证 | 1分 | 有效期内 |
| 电子信息行业相关软著/专利 | 1分 | 提供证书 |

### 4.3 类似业绩评分细则

```
类似业绩评分（满分6分）：
- 每提供一个与本项目类似的信息化项目合同业绩得2分
- 最多计3个业绩，满分6分
- 类似业绩指：合同金额≥本项目预算50%的同类医院信息化项目
- 须提供合同复印件（含合同首页、金额页、签字盖章页）及验收证明
```

### 4.4 售后服务评分细则

| 评分项 | 分值 | 评分标准 |
|--------|------|----------|
| 免费维护期 | 0-4 | 1年得2分，每增加1年加1分，满分4分 |
| 响应时效 | 0-1 | 7×24小时响应且严重故障2小时内到达得1分 |
| 培训服务 | 0-1 | 提供不少于2次现场培训且含培训方案得1分 |

### 4.5 团队配置评分细则

| 评分项 | 分值 | 评分标准 |
|--------|------|----------|
| 项目经理 | 0-1 | PMP认证或信息系统项目管理师证书得1分 |
| 技术人员 | 0-2 | 每名持有相关技术认证（如OCM、RHCE、软考中高级）得0.5分，满分2分 |
| 行业经验 | 0-1 | 项目经理具有3年以上医疗信息化项目经验得1分 |

### 4.6 本地化服务评分细则

| 评分项 | 分值 | 评分标准 |
|--------|------|----------|
| 常驻机构 | 2分 | 在本地有注册分支机构或常驻服务机构得2分 |
| 承诺服务 | 1分 | 承诺中标后30日内设立本地服务点得1分 |

## 五、评分汇总与中标确定

### 5.1 评分汇总

每位评委独立评分，汇总后计算算术平均值：

```
投标人总得分 = 价格得分 + 功能得分 + 商务得分
最终得分 = 全体评委对该投标人评分的算术平均值
```

### 5.2 中标确定

1. 按最终得分从高到低排序
2. 得分最高的投标人为第一中标候选人
3. 得分相同的，按投标报价由低到高排序
4. 得分且报价相同的，按技术指标优劣排序

### 5.3 评分争议处理

- 评委对同一评分项打分分值差距超过20%的，该评分项须重新评审
- 评委打分须书面说明理由，特别是最高分和最低分

## 六、禁止性条款

以下情形在评分标准中**不得出现**：

1. 对不同所有制、不同地区的企业实行差别待遇
2. 以特定行政区域或特定行业的业绩作为加分条件
3. 以特定品牌、专利、商标作为评分条件
4. 以资格条件作为评分条件（重复计分）
5. 将经营年限作为评分条件
6. 将注册资本作为评分条件
7. 设置与项目无关的资质要求
8. 规定投标人的特定规模条件
