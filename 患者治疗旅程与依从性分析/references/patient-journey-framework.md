# 患者旅程映射方法论与 5E 模型详解

## 一、患者旅程映射（Patient Journey Mapping）概述

患者旅程映射是一种系统性的研究方法，用于可视化患者从症状出现到治疗完成（或疾病终末期）的完整体验路径。该方法将患者的临床流程与情感体验、信息需求、决策行为整合在一起，帮助识别服务断点、体验痛点和可干预节点。

### 核心价值

- **全景视角**：将碎片化的患者体验串联为完整的旅程叙事
- **痛点定位**：精确定位患者在哪个环节、为什么感到困扰
- **决策洞察**：理解患者在每个关键决策点的思考过程和影响因素
- **干预设计**：为 PSP、数字化工具、患者教育提供精准的介入靶点

## 二、5E 患者旅程模型

### Entice（吸引）— 症状察觉与健康意识唤醒

- **触发事件**：身体症状出现 / 体检异常发现 / 家族史警示
- **患者行为**：自我评估 → 信息搜索（互联网/亲友）→ 决定是否就医
- **关键影响因素**：健康素养、疾病认知、对医疗体系的信任度
- **情绪状态**：不确定、担忧、试探性

### Enter（进入）— 首次就诊与诊断

- **核心流程**：选择就诊科室 → 初次就诊 → 检查检验 → 等待诊断 → 确诊
- **患者体验维度**：
  - 信息维度：对检查项目的理解、对诊断结果的认知
  - 时间维度：从首诊到确诊的时长
  - 沟通维度：医患沟通质量、诊断告知方式
- **情绪状态**：焦虑、恐惧、信息过载

### Engage（参与）— 治疗决策与起始

- **核心流程**：治疗方案讨论 → 治疗选择 → 知情同意 → 首次用药/治疗
- **决策影响因素**：
  - 医生推荐（最强影响因素）
  - 治疗预期获益 vs 风险
  - 经济负担与医保覆盖
  - 家庭意见
  - 信息获取（互联网/病友群/患者组织）
- **情绪状态**：希望与焦虑并存、决策压力

### Exit（退出/中断）— 治疗期间或治疗中断

- **核心流程**：持续用药 → 定期复查 → 疗效评估 → 副作用管理
- **关键场景**：
  - 治疗有效：维持治疗 → 定期随访
  - 疾病进展：换药决策 → 二线治疗
  - 不良反应：剂量调整 → 耐受管理
  - 治疗中断：依从性下降 → 停药脱落
- **情绪状态**：适应性变化、疲劳感累积、进展焦虑

### Extend（延续）— 疾病进展、方案切换与长期管理

- **核心流程**：进展识别 → 换药讨论 → 新方案启动 → 姑息治疗过渡
- **关键体验**：
  - 疾病进展的心理冲击
  - 后续治疗选择的有限性
  - 生活质量 vs 生存期的权衡
  - 临终关怀与心理支持
- **情绪状态**：挫败、接受、寻求支持

## 三、经典五大阶段模型（适用于肿瘤等慢性病）

### 阶段一：症状察觉与就诊（Pre-diagnosis）

| 维度 | 描述 |
|------|------|
| 典型时长 | 数天至数月（取决于疾病类型） |
| 关键决策点 | 是否就医、选择哪个科室 |
| 常见痛点 | 症状忽视/误判、科室选择错误、反复就诊未确诊 |
| 可干预节点 | 健康教育宣传、症状识别工具、就诊导航 |

### 阶段二：诊断阶段（Diagnosis）

| 维度 | 描述 |
|------|------|
| 典型时长 | 数天至数周 |
| 关键决策点 | 确诊方式、基因检测选择 |
| 常见痛点 | 等待焦虑、诊断告知冲击、基因检测认知不足 |
| 可干预节点 | 诊断等待期支持、基因检测教育、心理支持 |

### 阶段三：治疗决策与起始（Treatment Initiation）

| 维度 | 描述 |
|------|------|
| 典型时长 | 数天至两周 |
| 关键决策点 | 治疗方案选择、是否参与临床试验 |
| 常见痛点 | 方案理解困难、经济负担评估、家属沟通 |
| 可干预节点 | 共同决策支持工具、经济援助信息、新患者教育包 |

### 阶段四：治疗持续期（Treatment Continuation）

| 维度 | 描述 |
|------|------|
| 典型时长 | 数月至数年 |
| 关键决策点 | 副作用耐受判断、疗效评估后的方案调整 |
| 常见痛点 | 副作用管理、用药疲劳、随访不便、依从性下降 |
| 可干预节点 | 用药提醒、副作用管理工具、远程随访、心理支持 |

### 阶段五：疾病进展与方案切换（Progression & Switch）

| 维度 | 描述 |
|------|------|
| 典型时长 | 策略调整期 + 后续治疗周期 |
| 关键决策点 | 进展后治疗方案选择、临床试验入组评估 |
| 常见痛点 | 心理落差、后续方案认知不足、经济负担加重 |
| 可干预节点 | 进展心理支持、后续方案教育、援助项目衔接 |

## 四、患者旅程研究方法

### 定性方法

| 方法 | 适用场景 | 样本量 | 产出 |
|------|---------|--------|------|
| 患者深度访谈 | 深入理解体验与情感 | 15-30 人 | 旅程叙事、痛点清单、情绪曲线 |
| 患者日记研究 | 追踪日常治疗体验 | 10-20 人 | 时间线详细记录、实时痛点 |
| 焦点小组讨论 | 验证共性、对比差异 | 6-8 人/组 × 3-5 组 | 共识观点、群体差异 |

### 定量方法

| 方法 | 适用场景 | 样本量 | 产出 |
|------|---------|--------|------|
| 患者问卷调研 | 量化痛点、依从性、满意度 | 200-500 人 | 统计数据、优先级排序 |
| 真实世界数据分析 | 识别脱落模式和关键时点 | 数据库量级 | 流失率、依从性指标 |

## 五、患者情绪曲线描述规范

每个旅程阶段应标注以下情绪维度：

- **主要情绪**：该阶段最突出的情绪体验（如"焦虑/恐惧"）
- **情绪强度**：低 / 中 / 高 / 极高
- **情绪变化趋势**：上升 / 平稳 / 下降
- **影响行为的关键情绪**：直接驱动患者决策或行为的情绪因素

**示例**：
> 诊断阶段：主要情绪为"恐惧与焦虑"，强度"极高"，趋势"先升后缓"，关键影响行为包括"信息过度搜索"、"寻求第二意见"和"延迟治疗决策"。
